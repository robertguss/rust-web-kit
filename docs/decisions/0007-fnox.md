# 0007. fnox

## Context

Production needs `RWK_SESSION__SECRET`, SMTP, and OAuth client secrets. `.env` files get committed by accident. Cloud secret managers are heavier than a single-VM starter.

## Decision

fnox with the age provider. `fnox.toml` holds ciphertext under `[secrets]`. Recipients are age public keys. Operators run `fnox exec -- docker compose …` / `fnox exec -- just dev-api`. `.env.example` documents names only.

## Consequences

No plaintext secrets in git. Each operator (or host) needs an age identity (`~/.config/fnox/age.txt` or `FNOX_AGE_KEY`). The committed recipient is a placeholder until replaced. Agents must never print decrypted values.
