# 0001. SQLx

## Context

The API needs Postgres access with compile-time query checking, migrations, and a cache that CI can use without a live database. The workspace is on sqlx 0.9 (tokio + rustls).

## Decision

Use SQLx with `postgres`, `runtime-tokio`, `tls-rustls`, `macros`, `migrate`, `uuid`, `chrono`, `json`. Commit `.sqlx/` and run `cargo sqlx prepare --check` in `just check`. Apply schema with `just migrate`. Tests use `#[sqlx::test]` against real Postgres.

## Consequences

Queries are checked against the live schema during `just sqlx-prepare`. Offline builds work (`SQLX_OFFLINE=true`). Some ecosystem crates still pin sqlx 0.8; those are implemented in-tree rather than forcing a downgrade.
